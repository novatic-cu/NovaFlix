# Código de conducta

Este proyecto adopta el [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Nuestro compromiso

Nos comprometemos a que la participación sea una experiencia libre de acoso para todas las personas, independientemente de edad, diversidad corporal, discapacidad visible o invisible, etnia, identidad y expresión de género, nivel de experiencia, educación, situación socioeconómica, nacionalidad, apariencia, raza, religión u orientación sexual.

## Comportamiento esperado

- Empatía y amabilidad.
- Respeto a opiniones y experiencias distintas.
- Crítica constructiva y orientada al código, nunca a la persona.
- Reconocer el error propio y aprender de él.
- Priorizar lo mejor para la comunidad.

## Comportamiento inaceptable

- Lenguaje o imágenes sexualizadas, y atención sexual no deseada.
- Insultos, descalificaciones o ataques personales.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso.
- Conducta que razonablemente se considere inapropiada en un entorno profesional.

## Aplicación

Los mantenedores pueden eliminar, editar o rechazar comentarios, commits, issues y PRs que no cumplan este código, y comunicarán las razones cuando sea apropiado.

Reportes: **marcosjaviersantana300302@gmail.com**. Se revisan con confidencialidad. Las sanciones van desde una advertencia privada hasta el bloqueo temporal o permanente.
