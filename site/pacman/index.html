NovaFlix / pacman

Repositorio pacman

Binario oficial para Arch Linux, firmado y actualizado en cada release. No requiere AUR.

01
Clave pública

Registra y firma localmente la clave del repositorio.

sudo pacman-key --add https://novatic-cu.github.io/NovaFlix/pacman/x86_64/novaflix.gpg
sudo pacman-key --lsign-key F005E863F53A70D604479A369FE8FBEF7C2110F0
02
Repositorio

Añade el bloque a /etc/pacman.conf.

[novaflix]
SigLevel = Required DatabaseOptional
Server = https://novatic-cu.github.io/NovaFlix/pacman/$arch
03
Instalar

El paquete se llama novaflix-bin y declara provides=novaflix.

sudo pacman -Sy novaflix-bin
Con el repositorio configurado, paru -S novaflix-bin también resuelve el paquete. AUR sigue con el registro de cuentas cerrado; el paquete se publicará allí cuando reabra.

Paquete suelto (sin repositorio)

paru -U https://github.com/novatic-cu/NovaFlix/releases/latest/download/novaflix-bin-0.1.0-1-x86_64.pkg.tar.zst
