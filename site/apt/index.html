NovaFlix / APT

Repositorio APT

Índice Debian firmado, actualizado en cada release. Compatible con Debian 12, Ubuntu 22.04 y posteriores.

01
Clave de firma

Descarga y registra la clave pública del repositorio.

curl -fsSL https://novatic-cu.github.io/NovaFlix/apt/novaflix.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/novaflix.gpg
02
Repositorio

Añade el origen firmado a APT.

echo "deb [signed-by=/usr/share/keyrings/novaflix.gpg] \
https://novatic-cu.github.io/NovaFlix/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/novaflix.list
03
Instalar

El paquete se llama nova-flix; el binario instalado es novaflix.

sudo apt update && sudo apt install nova-flix
Actualizar: sudo apt update && sudo apt upgrade nova-flix. Desinstalar: sudo apt remove nova-flix.
